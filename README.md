# Vector Lab

An interactive retrieval-augmented generation pipeline and vector database simulator built with React, TypeScript, Vite, and Radix UI.

Explore document chunking, embeddings, vector search, similarity thresholds, top-k retrieval, reranking, context assembly, and grounded responses through a deterministic visual workflow.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
